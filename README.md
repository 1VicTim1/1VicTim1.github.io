# VicTim // Developer terminal

Адаптивный GitHub dashboard и конфигурируемый каталог Android-прошивок. Чёрный, кислотно-зелёный и жёлто-зелёный интерфейс. JavaScript ES modules и Vue 3 (актуальная стабильная 3.x скачивается и включается в сборку). После публикации Vue обслуживается с твоего домена, а не с CDN. Диаграммы — SVG и CSS, без тяжёлой библиотеки графиков.

## Публикация через сайт GitHub

1. Создай публичный репозиторий, например `dev-terminal`, с веткой `main`.
2. Загрузи содержимое этой папки **в корень репозитория**, сохраняя `.github/workflows/pages.yml`. При загрузке через веб-интерфейс отдельно проверь наличие скрытой папки `.github`.
3. Открой **Settings → Pages → Source → GitHub Actions**.
4. В **Actions → Update stats and deploy Pages → Run workflow** запусти публикацию. Адрес появится в завершённом задании `deploy` и в Settings → Pages.
5. Для максимально полного календаря можно добавить `GH_STATS_TOKEN` в **Settings → Secrets and variables → Actions**. Classic PAT без дополнительных scopes достаточно для публичных данных, если политики аккаунта позволяют; для fine-grained PAT проверь доступ к нужным публичным репозиториям. Не записывай токен в конфиг или браузерный JS. Сначала попробуй встроенный `GITHUB_TOKEN`: при недоступности календаря приложение покажет это явно, а коммиты продолжат собираться.

Работает и на `username.github.io`, и на `username.github.io/dev-terminal/`: все пути относительные, страницы используют hash-routing (`#/` и `#/roms`) и не требуют серверного fallback. Статистика пересобирается при push, вручную и каждые 6 часов. GitHub может задерживать cron; в неактивных публичных репозиториях расписание может отключаться. «Обновить» в браузере перечитывает уже созданный снимок, не запускает Actions.

## Что изменить

Всё пользовательское содержимое — в `site/config.json`:

- `profile.username`, `displayName`, `title`, `organizations` — профиль.
- `github.trackedRepositories` — внешние репозитории, где есть твои коммиты. Автоматически добавляются собственные репозитории и репозитории из календаря вкладов.
- `devices` — устройство → Android → семейство → версия прошивки.
- `status`: `official`, `unofficial` или `unknown` — **для каждой версии отдельно**.
- `downloadUrl` — настоящая страница загрузки, а не обязательно прямая ссылка на ZIP.
- `image` устройства и семейства — относительный путь, например `./assets/redmi12.webp` или `./assets/crdroid.png`. Положи файлы в `site/assets/`. Без изображения выводится текстовый шильдик. Новые изображения не нужно прописывать в коде.

Начальный профиль `1VicTim1` принят по предыдущему контексту. В каталоге задан Redmi 12 4G / Android 16 / crDroid 12.11. Это редактируемый пример по известной сборке июня 2026: **проверь версию и статус перед публикацией**. Другие прошивки не добавлены без данных.

Пример дополнительного семейства внутри `families`:

```json
{
  "name": "LineageOS",
  "image": "./assets/lineageos.png",
  "releases": [{
    "version": "23.0",
    "status": "unofficial",
    "downloadUrl": "https://example.com/your-actual-download-page",
    "note": "Укажи настоящую ссылку и подтверждённую версию."
  }]
}
```

## Данные и границы статистики

В сборке нет личного токена. Actions читает GitHub и публикует только публичный JSON `data/github.json`. Приватные репозитории не запрашиваются.

- Теплокарта: публичный GitHub contribution calendar за последние 12 месяцев — коммиты, PR, issues и другие типы вкладов. Не смешивается с числом коммитов.
- Гистограмма, список и рейтинг: найденные коммиты **только этого автора** в основных ветках отслеживаемых репозиториев за 7/30/90/365 дней. Коммиты других мейнтейнеров не учитываются.
- Языки: байты кода репозиториев, а не объём личного вклада. Звёзды: текущая сумма по проанализированным репозиториям, не накопление за период.
- Сбор ограничен 60 репозиториями и 1000 коммитами на репозиторий. Неполные данные и ошибки отдельных репозиториев показываются внизу страницы.
- Пока Actions не запущен, реальные числа отсутствуют. Демо включается отдельной кнопкой и всегда явно помечено как вымышленное.
- При ошибке основного запроса workflow завершается с ошибкой и не заменяет уже опубликованный сайт пустой статистикой.

## Локально

Node.js 22+ и Python 3:

```bash
npm run stats  # токен только через переменную окружения, если нужен
npm run build
python3 -m http.server 4173 --directory dist
```

Открой `http://localhost:4173`. В офлайн-окружении сборка для локального просмотра использует встроенный JS renderer; CI требует успешное включение Vue. `npm install` не нужен. Шрифты Google Fonts имеют системные fallback, сайт остаётся читаемым при блокировке сервиса.
